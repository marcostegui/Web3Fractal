# Web3Fractal

Cloud-based Fractal Engine enables real-time data processing through scalable, distributed architecture on a Blockchain-based Network.

With Web3Fractal, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/Web3Fractal.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Web3Fractal is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
